## 소개

4년 넘게 웹 프론트엔드를 만들어 왔고, 화면 개발에서 시작해 사내 디자인 시스템과 개발 환경처럼 여러 팀이 함께 쓰는 기반까지 만들고 있습니다. 현재 회사에서는 AI 에이전트 플랫폼 SurroAX의 PL로 요구사항을 검토하고 작업을 나눠 팀을 이끌고 있습니다.

팀이 같은 비효율을 반복하면 구조로 해결하는 편입니다. 보일러플레이트와 프로젝트 생성 CLI를 만들어 사내 프로젝트 6~7개가 같은 구조로 시작하게 했고, 화면과 백엔드 API의 어긋남은 MR 단계에서, 코드 구조 규칙 위반은 푸시 전에 자동으로 걸러지게 했습니다.

- SMDS 디자인 시스템(SurroAX 등 사내 UI 공용)과 Surro Q&A 웹: 앱 설치 패키지 6개 → 2개로 통합, 채팅 페이지 첫 로딩 JS 909kB → 692kB(24%) 감소, 화면과 백엔드 API의 어긋남을 MR 단계에서 잡는 검사 도입
- Next.js 보일러플레이트와 프로젝트 생성 CLI 배포: 사내 프로젝트 6~7개(다른 팀 2개 포함)가 이것으로 시작

주요 프로젝트: SurroAX, Surro Q&A, SMDS, 지식베이스 Q&A, 삼성E&A P&ID 관리 시스템, 온디바이스 RAG(정부 R&D), DocuMind, SurroDocs
